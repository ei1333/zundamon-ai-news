    Huawei Cloud、Agentic InfraとAI製品群を発表

    Huawei CloudはHuawei Cloud INSPIRE 2026で、Agentic AI向けの新基盤Agentic Infraを発表しました。AI Cluster Service、Agentic Memory Storage、CCE VolcanoNext、AgentSphereに加え、モデル訓練・推論基盤ModelArtsNextと企業向けエージェント基盤AgentArtsも打ち出しています。

    出典: Huawei

  3. 製品 電池 材料

    BASF、次世代EV電池向けOppanol N PLUSを発表

    BASFは、次世代EV電池向けの高性能バインダーOppanol N PLUSを発表しました。ポリイソブテン技術をもとに、固体電池などで部材を結着しながら機械的ストレスを吸収し、電池寿命や安定性に貢献する材料として位置づけています。
