2026-06-22 の公開情報から、systemd 261の新機能、AIコーディングエージェント向けのAgent Beacon、暗号化DNSのメタデータ漏れを扱う研究の3本をまとめています。

  1. OS クラウド インフラ

    systemd 261、クラウドメタデータとソフトウェアTPMを追加

    systemd 261では、クラウドインスタンスのメタデータをローカルのVarlink APIで扱うIMDSサブシステム、kexec再起動時の状態引き継ぎ、ソフトウェアTPMサービス、テキストベースのOSインストーラなどが追加されました。systemd-sysupdateは実験段階を離れ、systemd-networkdにはDHCPリレー関連の追加も入っています。

    出典: Help Net Security

  2. 開発 可観測性 セキュリティ

    Agent Beacon、AIエージェントの作業を記録するOSSとして登場

    Asymptote LabsのAgent Beaconは、Claude Code、Codex CLI、CursorなどのローカルAIコーディングエージェントが行う操作を、OpenTelemetryやフック経由で正規化されたJSONイベントとして記録するオープンソースツールです。ローカルダッシュボードやSIEM連携を想定し、プロンプトやコマンド出力などの保持範囲を選べるモードも用意されています。

    出典: Help Net Security

  3. ネットワーク プライバシー IoT

    暗号化DNSにも通信パターン漏れ、ヘッダー削減で対策を提案

    暗号化DNSは問い合わせ内容を守りますが、IPアドレス、ポート、シーケンス番号などの平文ヘッダーからDNSフローだと推測される可能性があります。研究チームはDNS over CoAP、ブロック転送、SCHCによるヘッダー削減を組み合わせ、IoT環境で識別精度を下げる手法を示しました。

    出典: Help Net Security
